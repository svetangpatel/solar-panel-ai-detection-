# ☀ AI Solar Panel Fault Detection System

An AI-powered web application that detects faults in solar panels using Deep Learning and Computer Vision.  
The system identifies dust, damage, shading and calculates efficiency loss to improve solar energy performance.

## 🚀 Features
- Upload solar panel image for detection
- Detect faults: Dust, Damage, Clean, Shaded
- Confidence score prediction
- Efficiency loss calculator
- Dashboard analytics
- Detection history storage (SQLite)
- Real-time camera detection (OpenCV)
- Web app built with Flask

## 🧠 Tech Stack
- Python
- TensorFlow / Keras (CNN - MobileNetV2)
- Flask (Web framework)
- OpenCV (Image processing)
- SQLite (Database)
- HTML, CSS

## 📊 How it Works
1. User uploads solar panel image
2. CNN model analyzes panel condition
3. System predicts fault type
4. Shows confidence and efficiency loss
5. Stores result in database dashboard
